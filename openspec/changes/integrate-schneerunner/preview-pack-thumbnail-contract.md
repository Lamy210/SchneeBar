# C3b draft: explicit bounded static thumbnails

Baseline fd94d16a after #406/#407 native CI. Use first frame of the actual declared default clip; no assumption that run is the default. Selection/restore may reuse its already validated decoded catalogue within the worker. An explicit photo placeholder request loads the full pack with existing byte/frame/pixel admission, then discards that catalogue; not a cheap decoder or guaranteed low-latency. Inventory refresh remains metadata-only and never automatically queues all packs. One shared library worker, no extra worker or timer. No preference writes for thumbnail requests. Output one owned 48x48 RGBA8 image, aspect fit with transparent margin; max 16 current UUIDs, 147456 bytes of nominal pixel payload, not total process RSS. No disk cache, no network. Invalidate on refresh, mutations, hide/sleep/stop and errors; filter on refreshed inventory, session-fence stale completions. Existing selection display may remain on hide; thumbnails are independent. Same-UID external content replacement remains outside guarantee until explicit refresh. Placeholder and accessible labels; no reliance on image to distinguish action. Native headless fixture verifies explicit load, size, no persistent selection, cache hit, refresh and visibility invalidation. Actual Mac UI/CPU/RSS and access controls remain unverified. No shipping linkage, no release, ADR/rights gates retained.
