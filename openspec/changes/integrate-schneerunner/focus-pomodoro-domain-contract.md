# E1c draft: finite native Pomodoro phase domain

Based on merged #438, independent of pending #439. Extend the existing pure FocusCore without new dependencies or changes to the previously merged countdown. Proposed native plan defaults: 4 focus rounds, 25-minute focus, 5-minute short break, 15-minute long break, long break every 4 completed focus rounds when another round remains. Session finishes after the final focus, without a trailing break; the default four-round plan therefore has three short breaks and no long break. Configurable round count and long-break cadence 1–12, each phase 1 second–24 hours. No claim of source compatibility; these defaults and bounds are subject to product approval.

Each session has a UUID, immutable plan, monotonic zero-based step, and independent FocusCountdown per phase. Explicit advance only after a completed non-final phase, with the new deadline based on the current supplied time. Waking late reconciles the current phase once, never auto-advances multiple phases or manufactures historical sessions. Pause/resume/cancel and advance are fenced by expected step; a future owner must also fence the session UUID and serialize current commands (reconcile is a current-state observation, not a queued captured-phase command). Within the same phase, repeated pause/resume use underlying countdown semantics. Late final-phase cancellation reconciles completion; late intermediate cancellation records that phase completion and ends the remaining session. Cancelling a waiting intermediate phase ends the session without a second completion. Completed and cancelled sessions cannot advance.

Version 1 Codable checks the plan through its validating initializer, step range before arithmetic or indexing, phase duration consistency and cancelled/terminal compatibility. Codable is not a durable file transaction, history, scheduler or notification receipt. Future persistence must commit before consuming a phase completion and use stable session/step identity. No imported notification activation. Backward wall-clock caveat from E1a retained. No shipping target dependency, timers, external effects or new Runner code. Tasks 4.1 and 9.6 remain partial.

Five new tests exercise exact deadline and full focus/short/long sequence, pause and waiting state encode/decode, early and stale commands, final versus intermediate late cancellation, and invalid plan/version/record. Linux Swift 6.2.1 isolated SwiftPM test passes 5/5, including existing FocusCountdown source, new source and tests verified by Git blob identity. Forcing all breaks to short gives five failed assertions in the cadence regression; restored source passes 5/5. No local harness or mutation is committed. Native Tuist/Xcode CI must execute the added tests; real-device, persistence, notifications, migration, UI, ADR and main promotion remain separate gates.
