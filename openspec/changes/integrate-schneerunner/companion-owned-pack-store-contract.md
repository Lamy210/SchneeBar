# C2b8 draft: canonical owned-copy transaction

Baseline integration bb010125 after #397–#401 native CI success. This developer-only API does not enable a picker, app startup, migration or source/asset reuse. Caller must supply an existing, exclusive app-managed local directory, not a user-selected destination, shared folder or existing Runner storage. Validate explicitly before real application support root creation. Same-user malicious process, ACLs granting access despite POSIX bits, root ancestor symlinks, mounts and concurrent directory relocation remain outside this first slice's ownership guarantee.

Capture manifest and immutable bounded image bytes during the same successful preflight/decode as the in-memory catalogue. Write only those captured bytes, never reopen a source URL, copy unreferenced entries or trust source filenames. Canonical character.json with generated ASCII state-derived names, extension from validated kind, numeric sequence names preserving loaded order. Preserve name/default/state/kind and original encoded image bytes; unknown source manifest keys are not copied. 32 MiB encoded plus manifest, 240 output frames, existing 16M work budget; source is never written. Return fresh UUID plus catalogue only after commit.

Open existing root O_DIRECTORY|O_NOFOLLOW, effective UID and no group/other mode bits. Random hidden stage, 0700 directories, O_EXCL/O_NOFOLLOW 0600 files, bounded writes and cancellation, fsync each file. Stage identity recheck and exclusive same-parent renameatx_np(RENAME_EXCL) is the atomic visibility commit; no replace, no partial published pack. Before commit undo only generated files/directories via descriptors, preserve existing packages; report cleanup failure. After commit report success rather than undo on cancellation. Not a power-loss durability guarantee: directory fsync/F_FULLFSYNC, crash journal/recovery, safe stage reclamation, aggregate library quota/index, reloading/selection/delete, duplicate detection and cross-process coordination remain separate. Single transaction, off-main caller required, no background tasks or UI. Existing real-device/rights gates unchanged.

Native tests: successful canonical roundtrip and source preservation, injected pre-rename failure after writing with clean rollback and existing pack retained, invalid input and unsafe symlink root rejection. Additional sequence roundtrip, write interruption, permissions, race, disk-full, cancellation and crash fixtures before production enablement. No distribution.
