# C3z draft: reversible owned-library management

Stacked on #431. Add explicit trash and restore actions through the existing exclusive worker slot. Require a current inventory and admitted asset session; no target paths, only canonical UUIDs. Track the admitted catalogue's identity independently of transient acquisition status, including after cancellation. Reject moving the currently displayed pack to trash. The new store trashUnselected checks the committed selection under the same exclusive root lock as the no-overwrite rename; a matching or malformed selection fails closed, never implicitly deselects. Keep the legacy preview trash behavior unchanged. Restore never chooses the restored pack. Existing active catalogue, CPU and local events remain unchanged on an otherwise stable host.

The editor uses a one-use confirmation bound to the action/UUID; invalidate on candidate, inventory, busy, availability or session changes. Invalidate metadata and preview when the operation begins; refresh explicitly after completion or an uncertain outcome. Trash retains the slot reservation and bytes. No purge, abandoned-stage removal, arbitrary cleanup, replay, polling or automatic selection repair. Cancellation revokes UI publication, not an already committed rename. The private-root lock covers cooperating callers, not external same-user mutation.

Two fixtures cover atomic saved-choice protection, malformed selection, reversible move, and displayed ID retention across cancellation, stale/duplicate confirmations and runtime/session preservation. Native CI, actual Mac UX, destructive recovery/purge UI, shipping wiring, rights and ADR/main approval remain pending.
