# C3x draft: explicit owned pack import
Based on merged #429. Import a user-selected directory into the existing private owned library using the existing validated copy transaction, slot limits and exclusive root lock. No source bookmarks, paths in status text, automatic selection, external store mutation or background import. Security-scoped access is balanced in the actual worker. Only the installed UUID is returned; do not retain or adopt the decoded catalogue. Inventory and thumbnail are invalidated when an import starts; explicitly refresh the inventory before another UI import. The store rechecks capacity and recovery conditions, regardless of the UI snapshot.

The editor requires an admitted, idle host and a current inventory allowing import. A native directory chooser uses a one-use token invalidated on relevant lifecycle or operation transitions. The host also checks the captured asset session and image ownership. Import owns the same exclusive worker slot, including after cancellation until actual drain. Runtime revocation suppresses late publication, not an already committed filesystem rename; refresh to discover whether an interrupted import committed. No automatic retry or cleanup. The admitted catalogue, saved selection, CPU and event session are unchanged on an otherwise stable host.

Two fixtures exercise actual copy and selection/source preservation, stale modal token and inventory invalidation, and cancelled non-cooperative worker exclusion. Native CI, actual panel accessibility/sandbox behavior, single-image import, library deletion/recovery UI, approved artwork, ADR and main promotion remain pending. No shipping target dependency or release.
