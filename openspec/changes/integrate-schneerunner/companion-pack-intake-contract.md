# C2b4 draft: versioned pack manifest and descriptor-confined regular files

Baseline Runner c925816d4f7ec4e07a5c6db74fd6038fea3aa71d CharacterPack.swift/CharacterPackLoader.swift/CharacterPackResourceResolver.swift. Independently implemented observable format: directory .schneerunner, character.json, formatVersion=1, name/defaultState/clips[{state,kind,path}], five states and six known kinds. Recognition is not decoding support. Runner has 64 KiB manifest, 240 frames, 32M decoded pixels; Bar retains its stricter 16M catalogue pixel policy. Future loader must establish an aggregate encoded-byte/frame/pixel preflight budget before decode, separate from per-file limit and retained catalogue.

Manifest Data <=64 KiB, UTF-8, rejects empty/NUL, invalid version/name/duplicates/missing default, 1..5 clips. Names 80 characters and <=1024 bytes, trim/control rejection. Bounded relative paths <=1024 bytes, 16 components, <=255 bytes each, no dot/dot-dot/empty/backslash/colon/control. Additional limits intentionally stricter than Runner. JSONDecoder ignores unknown keys and does not guarantee rejection of duplicate JSON keys; no signing/authorization semantics. A recognized pngSequence path is a directory, not supported by regular-file reader. No decoder or pack install/persistence added.

Selected root directory opened once O_DIRECTORY|O_NOFOLLOW; root ancestors are not claimed symlink-free. Traverse manifest-relative directory components with openat O_DIRECTORY|O_NOFOLLOW, leaf O_NOFOLLOW|O_NONBLOCK; validate descriptor type, same device and regular leaf link count exactly one before/after read; no path re-resolution after opening root. Reject symlinks below/root itself, hardlinked regular leaves, FIFO/directory and crossing devices. Directory descriptors retained during traversal; root rename/replacement cannot redirect lookup to a newly placed root. Not a snapshot or protection against malicious concurrent rename of already-open subdirectories outside root, same-device mounts, file modification after checks or OS allocation/blocking. No directory enumeration or untrusted archive extraction. Future staging must copy verified bytes to private owned directory with atomic rename and rollback, and validate source/destination under concurrent mutation. Use off-main worker, cancellation and balanced selected security scope in future caller. No production dependency added.

Seven native regression fixtures: six recognized kinds; version/name/duplicate/default; lexical traversal/size limits; exact manifest cap and malformed UTF-8; bounded nested read; root/intermediate/leaf symbolic links, hardlinks, FIFO; selected root path replacement. macOS CI and real-device adversarial mutation checks remain required. Do not complete C2b/C2c tasks or enable pack selection.
