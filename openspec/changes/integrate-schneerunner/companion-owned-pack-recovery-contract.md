# C2b10 draft: reversible trash and explicit bounded recovery

Stacked on #403. Cooperating operations hold the nonblocking exclusive root flock. Trash/restore accepts UUID only, pins private same-device child, verifies identity, then exclusive rename between canonical UUID.schneerunner and .trash-UUID. No overwrite or implicit purge; trash counts as an occupied slot (16 total), and is not selectable. Inventory reports ordered trash and abandoned stage UUIDs. Restore retains UUID, and subsequent load revalidates assets. UI must switch active selection to default before trash and not implicitly restore a deleted selection. No user interface or selection persistence in this slice.

Explicit purgeTrash and discardAbandonedStage validate the entire bounded generated layout before first unlink: only character.json, one state-named PNG/GIF/WebP leaf or state-named directory containing frame-000.png through frame-119.png, at most 240 sequence files total; root scan <=8 incl dot entries, nested scan <=122. Missing or empty partial files are allowed for recovery; no parsing of an incomplete manifest. Require private UID/mode, same device, regular single-link leaves with no-follow stat; never follow symlinks or recurse into unknown subdirectories. Any unknown or malformed name/type rejects preflight without mutation. Keep descriptors through operation, verify identity again before each unlink and remove directory only when empty. Unknown outside target untouched. Cancellation before deletion leaves bytes intact; once deletion starts finish bounded operation or report error, never claim transactional rollback of unlink. Partial repeated purge is retryable, tombstone/stage remains until directory removed. No auto-cleanup at startup. Name matching alone is not provenance: only app-owned exclusive root, no untrusted user-selected or Runner root. Same-UID noncooperating race between fstatat/unlinkat, ACL, ancestor/mount, power loss and crash durability remain outside protection. Reclamation does not securely erase bytes or guarantee exact physical space.

Four native tests: trash/restore/purge and quota, no-overwrite and symlink refusal, whole-target preflight rejection without deleting existing file, explicit recovery of incomplete sequence stage preserving committed pack. Require native CI and real filesystem fault tests, including partial unlink failure/retry and adversarial mutation. No production wiring or release.
