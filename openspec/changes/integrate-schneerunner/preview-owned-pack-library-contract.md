# C3b draft: preview-owned persistent selection

Baseline fa7544eb, #404/#405 native success. Explicit Start after conflict and status item checks creates one fixed Application Support child (0700); parent must exist; no source bookmarks, Runner or shipping store. Existing roots are checked, never chmodded. Headless tests do not use real user storage unless a test root is injected.

One noncancelling off-main durable worker per model; mutually exclusive with the single-image queue, including cancelled but still executing work. No worker at init or failed Start. Stop fences publication, blocks restart until exit; no claim that committed filesystem operations can be cancelled. Hide/sleep fence session publication, reload persisted state after the worker exits and a new valid session is present. If a retained image worker prevents automatic restoration, show explicit retry. Single-file/session default changes are transient; persistent choice only via Select/Use built-in. Import copies without selecting. Refresh metadata only; restore fully validates. Listing failure after commit separately reported. No protection from immediate process termination or noncooperating same-user writes.

Existing SchneeSurface, bounded list, explicit directory picker, generic errors and slot counts. No thumbnails, trash/purge/recovery UI or shipping linkage. Two native fixtures cover import/select/restart/default and exclusion of a cancellation-resistant image worker. macOS CI, real panel, actual APFS permissions, stop/sleep/quit, accessibility, peak old/new memory, rights and ADR gates remain. No distribution.
